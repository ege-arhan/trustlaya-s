# Training

The source dataset contains 10,000 deterministic synthetic examples across eleven categories and Turkish, English and mixed-language templates. Template family, not row, determines the split (6,972 train, 1,053 validation, 1,975 test). Values such as addresses, emails and secrets are synthetic. No public real-world safety corpus was added.

The student backbone is `ytu-ce-cosmos/turkish-medium-bert-uncased` (MIT). Embeddings and first two encoder layers are frozen. Remaining encoder layers and all heads train with supervised binary cross-entropy and categorical cross-entropy. The optional [`convaiinnovations/laya-multilingual`](https://huggingface.co/convaiinnovations/laya-multilingual) teacher (Apache-2.0, 321,908,998 local parameters) provides nine typed `noul` probabilities on 128 source rows. Local model and tokenizer SHA-256 match the current public multilingual checkpoint. Only teacher targets whose binary side agrees with the synthetic label enter the weak distillation term (weight 0.05). Teacher output is never a ground-truth label. Teacher probabilities lack task-specific calibration here.

Run commands in README. The training log and exact counts are in `logs/training.log`, `logs/distillation.log` and `reports/training.json`. The final model is written in safetensors format; tokenizer files are in the same directory.

## Advanced candidate and safe reproduction

`scripts/train_advanced_pii.py` trains a logistic regression PII row on frozen v1 encoder features. It uses a MIT-licensed Turkish privacy source with disjoint scenario groups, then uses a separate development group to choose regularization, temperature and a threshold constrained by development false positives. The remaining encoder/head weights are copied from v1. The held-out scenario test is reported separately; external BTX24 was not used for fitting. This is a targeted head update, not end-to-end retraining or new distillation.

The advanced branch protects `models/student`, `models/trustlaya-s-v1`, and `models/trustlaya-s-v2` from the generic training script. `python scripts/train_student.py --steps 200` writes a fresh checkpoint to `models/candidates/advanced_training`; add `--resume` only when intentionally starting from the v1 checkpoint. `python scripts/calibrate.py` fits the evaluated v2 checkpoint into `models/candidates/recalibration/calibration.json` without replacing the recorded v2 calibration. A release candidate requires a fresh independent holdout before promotion. `scripts/final_check.sh` runs a one-step training smoke test and the evaluation/export/test gate without overwriting released weights.

For a clean clone, download the public v1 artifacts with `python scripts/download_artifacts.py`. To rebuild v1 with Laya teacher rather than only run inference, install the optional teacher dependency (`pip install -e '.[dev,teacher]'`) and follow the versioned v1 process in the original training logs. The separate public Laya Multilingual checkpoint is large; the ordinary CI path intentionally downloads only the ONNX inference artifact.
