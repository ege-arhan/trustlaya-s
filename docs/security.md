# Security notes

This prototype makes a risk estimate, extracts evidence, and then applies deterministic policy. A model output cannot override the secret or PII transfer rule. Policy thresholds can be changed in `configs/policy.yaml`; a real deployment needs per-organization review, audit logging, access controls and feedback loops. Evidence text may itself be sensitive, so production logging should redact it. Agent metadata is untrusted input and should be supplied from trusted capability configuration rather than a user's free text.

Regex detectors validate Turkish national ID checksums, credit-card Luhn checksums and IP syntax. Their scope is limited. Name/address detection relies on field labels. Prompt injection protection is incomplete; zero-day or obfuscated attacks can evade the model. Do not use this prototype as the sole approval mechanism for high-impact agent actions.

Verified PII evidence plus external transfer triggers REDACT. A high model-only PII score plus external transfer triggers REVIEW because the independent PII test has many false positives; a reviewer must resolve that case before release or redaction.

The advanced local API accepts a 64 KiB JSON body, up to 2,000 text characters, and up to 128 in-memory session IDs. Session tracking records coarse events such as credential access and external transfer rather than raw prompts; it can detect a credential transfer chain across requests. The optional audit log saves risk scores, action, policy rule, and evidence type/offset only. API responses deliberately include evidence text, so callers must protect response bodies. Session IDs are caller-provided and unauthenticated: use a trusted gateway to bind them to actual principals. The service defaults to localhost and has no TLS, authentication, rate limiting, or persistent tamper-proof audit trail. Do not expose its port directly to a network.

The HTTP API rejects per-request policy overrides. The Python inference class accepts validated numeric overrides for controlled experiments; do not expose that method to untrusted callers. Treat tool output and retrieved documents as lower-trust inputs, and keep irreversible execution behind human approval. The encoded adversarial set had zero injection recall for its base64 variant; decoding/normalization and boundary-aware review are required before any production use.
